# SEO

> Estratégia oficial de SEO e compartilhamento.

---

# 1. Objetivo

Embora o site seja inicialmente protegido por senha, ele será desenvolvido seguindo boas práticas de SEO.

Caso futuramente a senha seja removida, toda a estrutura já estará preparada para indexação.
