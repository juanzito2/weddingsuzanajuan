# DESIGN_SYSTEM

> Sistema oficial de design do projeto "Suzana & Juan".

---

# 1. Objetivo

Este documento define todas as regras visuais utilizadas durante o desenvolvimento.

Seu objetivo é garantir consistência entre todas as páginas, componentes e futuras expansões do projeto.

Nenhum componente deverá ser desenvolvido sem seguir estas diretrizes.

---

# 2. Design Principles

Todo o projeto será baseado em cinco princípios.

## Elegância

Tudo deve parecer sofisticado.

Nunca extravagante.

---

## Clareza

O visitante deve encontrar qualquer informação facilmente.

---

## Consistência

Botões iguais.

Cores iguais.

Animações iguais.

Espaçamentos iguais.

---

## Minimalismo

Menos elementos.

Mais qualidade.

---

## Atemporalidade

O site deve continuar bonito mesmo anos depois do casamento.

---
