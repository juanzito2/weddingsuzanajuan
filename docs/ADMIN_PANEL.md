# ADMIN_PANEL

> Documentação oficial do Painel Administrativo.

---

# 1. Objetivo

O painel administrativo será o centro de controle do casamento.

Toda a administração do evento deverá ser realizada através desta área.

Somente administradores autorizados terão acesso.

---

# 2. Login

O acesso será realizado através de:

- E-mail
- Senha

Após autenticação, o sistema verificará as permissões do usuário.

Caso não possua autorização, o acesso será negado.

---

# 3. Dashboard

Ao entrar no sistema, o administrador visualizará um resumo geral.

Indicadores principais:

- Total de convidados
- Total de famílias
- Confirmações aprovadas
- Confirmações pendentes
- Confirmações recusadas
- Fotografias pendentes
- Fotografias aprovadas
- Fotografias rejeitadas

Também será exibida a contagem regressiva para o casamento.

---

---

# 14. Interface

O painel seguirá a mesma identidade visual do site.

Entretanto utilizará:

Mais branco

Mais cinza claro

Menos elementos decorativos

Maior foco na produtividade.

---

# 15. Objetivo Final

Permitir que qualquer pessoa da organização consiga administrar todo o casamento sem conhecimentos técnicos.
