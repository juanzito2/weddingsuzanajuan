# BRANDBOOK

> Identidad visual oficial del sitio web del matrimonio de Suzana y Juan.

---

# 1. Introducción

Este documento define la identidad visual oficial del proyecto.

Su objetivo es garantizar que todos los elementos del sitio web mantengan el mismo lenguaje visual, independientemente de cuándo sean desarrollados.

Toda nueva pantalla, imagen, icono, animación o componente deberá respetar estas directrices.

---

# 2. Concepto

El sitio web está inspirado en dos pilares principales.

## 60%

Hotel europeo de lujo.

## 40%

Boda real contemporánea.

El resultado debe transmitir elegancia sin exageraciones.

---

# 3. Personalidad

El sitio debe sentirse:

- Elegante
- Exclusivo
- Sofisticado
- Moderno
- Sereno
- Luminoso
- Organizado
- Atemporal

Nunca debe sentirse:

- Infantil
- Exagerado
- Recargado
- Medieval
- Oscuro
- Barroco
- Genérico

---

# 4. Filosofía

Menos elementos.

Más calidad.

Más espacio.

Más armonía.

Cada detalle debe tener un propósito.

---

# 5. Inspiraciones

El diseño toma inspiración en:

- Hoteles cinco estrellas europeos.
- Bodas de lujo.
- Diseño editorial.
- Revistas premium.
- Arquitectura clásica con estilo moderno.

---

# 6. Paleta oficial

## Imperial Purple

Color principal.

Representa:

- Realeza
- Nobleza
- Elegancia

---

## Royal Lavender

Color secundario.

Representa:

- Delicadeza
- Amor
- Calma

---

## Champagne Beige

Representa:

- Sofisticación
- Lujo
- Neutralidad

---

## Royal Gold

Uso limitado.

Solo para pequeños detalles.

Nunca dominará el diseño.

---

## Ivory

Color principal para fondos.

Debe generar sensación de amplitud.

---

## White

Para destacar elementos importantes.

---

# 7. Gradientes

Los gradientes serán suaves.

Nunca muy saturados.

Ejemplos:

Imperial Purple

↓

Royal Lavender

↓

Champagne Beige

---

Nunca utilizar degradados muy fuertes.

---

# 8. Estilo fotográfico

Las fotografías deberán transmitir:

- Luz natural.
- Colores suaves.
- Elegancia.
- Sonrisas espontáneas.
- Romanticismo.
- Ambientes luminosos.

Evitar:

- Filtros exagerados.
- Saturación alta.
- Contrastes extremos.

---

# 9. Monograma

El monograma será el símbolo oficial del matrimonio.

Estará presente en:

- Página inicial.
- Pantalla de carga.
- Footer.
- Favicon.
- Open Graph.
- Invitaciones digitales.
- Código QR.
- Galería.

---

## Estado actual

Actualmente existe una primera versión.

Será refinada durante el desarrollo.

---

## Futuras versiones

- Logo principal.
- Logo horizontal.
- Logo vertical.
- Favicon.
- Versión monocromática.
- Versión blanca.
- Versión dorada.
- Marca de agua.

---

# 10. Iconografía

No utilizar emojis.

Todo el proyecto utilizará:

- SVG
- Iconos minimalistas
- Ilustraciones discretas

Todos deberán compartir el mismo estilo.

---

# 11. Tipografía

La selección definitiva será realizada durante el desarrollo.

Se utilizarán únicamente dos familias tipográficas.

## Fuente para títulos

Elegante.

Con personalidad.

---

## Fuente para textos

Muy legible.

Pensada para largas lecturas.

---

# 12. Animaciones

Las animaciones deberán ser discretas.

Permitidas:

- Fade
- Reveal
- Hover
- Scroll
- Microinteracciones

No permitidas:

- Rebotes exagerados.
- Zoom agresivo.
- Efectos llamativos.
- Animaciones rápidas.

---

# 13. Ilustraciones

Cuando una sección requiera una imagen personalizada, esta será diseñada específicamente para el proyecto.

No se utilizarán imágenes genéricas si pueden afectar la identidad visual.

Todas las ilustraciones deberán seguir el mismo estilo artístico.

---

# 14. Componentes

Todos los componentes compartirán el mismo lenguaje visual.

Botones.

Tarjetas.

Formularios.

Alertas.

Modales.

Menús.

Galerías.

Todos deberán parecer parte del mismo sistema.

---

# 15. Espaciado

El sitio respirará.

Se priorizarán grandes espacios en blanco.

Nunca se saturarán las páginas.

---

# 16. Experiencia del usuario

La navegación debe sentirse:

Natural.

Suave.

Elegante.

Sin interrupciones.

El usuario nunca deberá sentirse perdido.

---

# 17. Accesibilidad

El sitio será desarrollado considerando:

- Contraste adecuado.
- Navegación mediante teclado.
- Textos legibles.
- Buen tamaño de botones.
- Compatibilidad con dispositivos móviles.

---

# 18. Evolución de la identidad

Durante el desarrollo se crearán nuevos recursos gráficos.

Cada nueva imagen será documentada y añadida al proyecto.

Entre ellos:

- Refinamiento del monograma.
- Fondos.
- Hero principal.
- Íconos.
- Favicons.
- Open Graph.
- Pantalla de carga.
- Página 404.
- Recursos para redes sociales.

---

# 19. Principio fundamental

La elegancia no nace de añadir elementos.

La elegancia nace de eliminar todo aquello que no aporta valor.
