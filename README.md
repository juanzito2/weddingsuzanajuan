# 👑 Suzana & Juan

> Sitio web oficial del matrimonio de Suzana y Juan.

---

## Descripción

Este proyecto contiene el desarrollo completo del sitio oficial de la boda de Suzana y Juan.

Más que una página web, este proyecto busca ofrecer una experiencia elegante, organizada y memorable para todos los invitados, combinando diseño moderno, identidad visual exclusiva y una administración sencilla para los organizadores.

Todo el desarrollo ha sido pensado para ser mantenible, escalable y completamente documentado.

---

## Objetivos

- Presentar la información oficial del matrimonio.
- Permitir la confirmación de asistencia (RSVP).
- Facilitar la administración de invitados.
- Publicar fotografías oficiales antes y después del evento.
- Ofrecer una experiencia bilingüe (Español y Portugués).
- Mantener una identidad visual elegante inspirada en hoteles de lujo y bodas reales.
